# FlowSync — AI Customer Support Assistant

## Problem
Customer support operations needed improved efficiency and experience, with an opportunity to use AI to reduce manual workload.

## Approach
- Conducted business analysis on existing support workflows
- Designed an AI-assisted workflow to handle common support cases
- Identified process improvement opportunities
- Gathered requirements and wrote user stories for the AI assistant
- Defined success metrics to evaluate impact

## Outcome
A workflow design and set of success metrics demonstrating how AI integration can improve customer experience and operational efficiency.

## Skills Demonstrated
Business Analysis · AI Integration · Process Improvement · Requirements Gathering · User Stories · Customer Experience · Workflow Design · Product Thinking · Success Metrics

# FlowSync — AI Customer Support Assistant

## Problem
Customer support operations needed improved efficiency and experience, with an opportunity to use AI to reduce manual workload and response times.

## Approach
- Conducted business analysis on existing support workflows and stakeholder needs
- Documented business, functional, and non-functional requirements, plus user stories, for an AI-assisted support workflow
- Designed an AI assistant workflow covering intent recognition, knowledge base search, and intelligent escalation routing to human agents
- Analyzed 2,500 simulated support conversations using SQL — AI resolution rate, escalation reasons, and response times by issue category
- Used Python for exploratory analysis of AI performance and customer satisfaction trends
- Built an interactive Tableau dashboard tracking AI resolution rate, escalation patterns by issue type, CSAT, and estimated cost savings

## Outcome
The AI assistant resolved 69.6% of 2,500 support conversations, with resolution rates improving from 61% to over 75% across a 6-month period, and an estimated $20K in support cost savings. Analysis also revealed resolution performance varies significantly by issue category — Billing showed the lowest AI confidence and highest escalation rate, while categories like Account Management were well-handled by AI — informing where to prioritize future AI training investment.

## Skills Demonstrated
Business Analysis · Requirements Gathering (BRD/FRD/NFR) · User Stories · SQL · Python · AI Workflow Design · Dashboard Design (Tableau) · Process Improvement · Customer Experience · Success Metrics
